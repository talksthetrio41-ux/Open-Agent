# Open Agent

See `AGENTS.md` for the current architecture.

This project is a **free Android/Termux coding agent**. It signs into [chat.qwen.ai](https://chat.qwen.ai) with Chromium, runs shell commands on the phone, and stores files in the user’s GitHub repo.

One-command Termux install:

```bash
curl -fsSL https://raw.githubusercontent.com/talksthetrio41-ux/Open-Agent/main/install.sh | bash
```
